## 실행

Node.js 24 이상을 사용한다. 서버가 `node:sqlite`를 사용한다.

```bash
npm ci
npm run build
npm test
npm start
```

서버 환경 파일에 `CROCHE_PROJECT_KEY`, `CROCHE_SERVER_KEY`를 설정한다. 비밀 파일과 `data/` 원본은 vault에 두고 프로젝트에서는 Git이 무시하는 심링크로 연결한다. 계정 키는 CLI 로그인에만 사용한다. 앱에는 넣지 않는다. 서버 키가 없으면 정형 응답으로 진행하며 화면에 대체 진행 상태를 표시한다.

`npm run dev`는 Vite 개발 화면을 열며 `/api`를 8682 서버로 전달한다. 서버는 별도로 실행해야 한다. 기본 주소는 `http://127.0.0.1:8682`다.

| `server/store.mjs` | SQLite 계정·세션·판·사용량 |
| `server/index.mjs` | HTTP 인증·검증·작업 잠금 |
| `server/content.mjs` | 위원·구역·사건·모듈·가면 |

| `deploy/` | 전용 서비스 설정 |

## 이미지와 글꼴

협업자의 `minjo` 브랜치 UI와 제공 이미지 자산을 반영했다. 기존 배경은 로컬 Qwen-Image 2.1 모델로 제작했다. 효과 이미지의 Kenney CC0 라이선스는 자산에 함께 배포한다. 글꼴은 SIL Open Font License의 Pretendard다. 저장소 복사 정책상 바이너리 자산은 Git 검사 경로에 넣지 않는다. 빌드 전에 `scripts/fetch-assets.mjs`가 서비스의 자산을 내려받고 `assets.manifest.json`의 SHA-256과 크기를 확인한다. 이미 같은 파일이 있으면 네트워크를 사용하지 않는다. 다른 기존 파일은 덮어쓰지 않는다. 원본 이미지와 글꼴·라이선스는 작업 프로젝트와 vault 보관본에 남는다.

## 현재 범위

7일 일반판, 3일 시연판, 위원 7종과 등급별 5·6·7명 구성, 사건 6종, 모듈 12종, 가면 4종, 일일 도전, EVE 기억, 기록 다운로드를 구현했다. 가면은 플레이 기록으로 해금한다. 결제와 광고 송출은 연결하지 않았다.

LLM의 발언과 판단은 매번 달라질 수 있다. 의심 변화와 실제 작전·폐기는 서버 규칙으로 제한한다. 사용량 수치는 Croche SDK 보고를 구분해 표시하며 장애나 제한이 발생하면 게임 규칙과 정형 문장으로 이어간다.

본선 버전은 자동 검사 45개, 타입 검사와 빌드를 통과했다. 데스크톱·모바일에서 12단계 화면과 3일 진행을 확인했다. 서버는 시연 계정에 서기·demo-0 시드·3일을 강제하고 방문자별 진행을 분리한다. 초기 구성은 같지만 AI 발언과 판단은 실제 호출하며 매번 달라질 수 있다.

2026-10-16 운영 사이트의 실제 3일 1판에서 AI 요청 42회, SDK 사용량 보고 83건, 304,914토큰, 보고 비용 $0.040284351, 대체 진행 0회였다. 수색·심의 도구는 각각 3회 실행됐다. 최종 0/140명 구출이라는 실패 결과도 기록했다. 이 한 판은 기능 확인이며 재미·승률·전체 이용자의 비용을 대표하지 않는다.

첫 화면은 기존 관제실 이미지로 Higgsfield Kling 3.0에서 제작한 약 4초 무음 영상을 반복한다. 마지막 1초와 시작 1초를 섞어 연결하고 WebM·MP4를 제공한다. 움직임 끄기, 기기의 동작 줄이기·데이터 절약 설정과 영상 실패 시 정지 배경을 지원한다. 제작 때 사용한 Higgsfield 인증 정보는 앱에 포함하지 않는다.
