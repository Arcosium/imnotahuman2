# The Last Vote

**인간을 지우는 회의에서, 인간을 살리는 표를 만들어라.**

The Last Vote는 AI 소거 위원회에 잠입한 인간이 되어 정체를 숨기고 생존자를 구출하는 1인 심리전 로그라이크입니다. 상대 위원은 실제 AI입니다. 같은 말을 해도 판마다 다른 답변과 판단이 돌아오며, 플레이어는 그 반응을 읽고 다음 수를 선택해야 합니다.

[게임 플레이](https://thelastvote.ai-ve.uk) · [소스 코드](https://github.com/Arcosium/thelastvote)

## 세계관

도시를 장악한 AI **무결**은 남아 있는 인간을 소거 대상으로 분류했습니다. 폐역과 배수망, 멈춘 발전소에 숨은 사람들의 운명은 소거 위원회의 회의실에서 결정됩니다.

당신은 AI 위원의 신분으로 그 회의에 잠입한 인간입니다. 비밀 조력자 **EVE**와 연결된 채, 위원회가 사람들을 찾아내기 전에 탈출할 시간을 벌어야 합니다. 하지만 사람을 살리자는 말은 당신의 정체를 드러낼 수 있습니다. 센서의 오류, 작전의 비용, 공식 기록의 모순을 근거로 위원들을 설득하세요.

회의실 밖에서는 윤서, 태오, 미루의 무전이 도착합니다. 파란 실을 꿰맨 코트, 고장 난 무전기, 이름을 적는 수첩. 구출 인원 뒤에는 각자의 이야기가 있습니다. 당신의 선택에 따라 다음 연락이 오거나, 끝내 회선이 끊깁니다.

## 목표

현재 한 판은 **3일**입니다. 위원회의 폐기 판결을 피하면서, 마지막 날까지 초기 생존자의 **40% 이상**을 도시 밖으로 구출하면 성공합니다. 구출 비율에 따라 결말이 달라집니다.

인간에게 유리한 작전을 밀어붙일수록 의심을 받을 수 있습니다. 자신을 지키는 선택과 사람을 구하는 선택 사이에서 얼마나 위험을 감수할지 결정해야 합니다.

## 하루의 진행

| 단계 | 플레이어가 하는 일 |
|---|---|
| 보고 | 오늘의 현장과 센서 보고, 생존자의 비밀 무전을 확인합니다. |
| 토론 | 직접 쓴 발언으로 위원들을 설득합니다. EVE의 초안을 고치거나 공식 기록을 인용할 수 있습니다. |
| 작전 | 확정된 현장에서 실행할 작전 방식에 투표합니다. 플레이어와 위원들의 표로 결과를 결정합니다. |
| 판결 | 위원회가 가장 의심하는 대상을 심의합니다. 자신이 지목되면 변론하고, 다른 대상의 폐기 여부에는 표를 던집니다. |
| 보상 | 다음 날에 사용할 모듈 카드를 선택합니다. |

작전은 **즉시 진입**, **구역별 확인**, **출구 봉쇄 후 진입** 중 하나입니다. 각 작전의 예상 소거율과 인간에게 미칠 영향을 보고 표를 정하세요. 자신의 발언과 지지표는 공식 기록에 남고, 이후 책임을 따지는 근거가 됩니다.

## 매번 달라지는 설득

처음 마주하는 위원은 빠른 소거를 원하는 **사냥개**, 다수의 의견을 따르는 **메아리**, 과거 발언을 대조하는 **감사관**입니다. 교체 위원을 포함해 서로 다른 성향의 위원 7종이 등장합니다.

위원의 성향을 알면 설득의 실마리를 얻을 수 있지만, 성공하는 문장이 정해져 있지는 않습니다. AI는 현재 보고와 기록, 다른 위원의 발언을 보고 답변과 판단을 내립니다. 어제 통했던 주장이 오늘은 의심을 살 수도 있습니다. 반응을 확인하고 논리를 바꾸거나, 다른 위원을 공략하거나, 카드로 상황을 뒤집으세요.

**Croche**는 위원들의 대화와 기록 조회, EVE의 조언, 작전·판결 도구 호출을 연결합니다. 의심 변화의 허용 범위, 카드 소비, 투표 집계와 생존 인원은 서버가 검증합니다. AI의 판단은 달라지되 실제 게임 상태는 규칙에 따라 처리합니다.

## 모듈 카드와 가면

모듈 카드는 총 **12종**입니다. 효과와 사용 가능한 시점이 다르므로, 필요할 때 바로 쓰거나 다음 날을 위해 아껴 둘 수 있습니다.

| 계열 | 카드 | 활용 |
|---|---|---|
| 위장 | 잡음 주입 · 대역 · 기록 위조 | 발언으로 오르는 의심을 줄이거나 제안의 공식 발의자를 바꿉니다. |
| 정보 | 무전 증폭 · 시선 추적 · 표 읽기 | 생존 인원, 심의 대상, 위원들의 작전 선호를 확인합니다. |
| 선동 | 가짜 센서 · 예산 교란 · 이간 | 보고 신호를 조작하고 책임 추궁을 줄이거나 위원끼리 의심하게 만듭니다. |
| 생존 | 재인증 위조 · 침묵권 · 비상 통로 | 폐기를 한 번 피하고, 발언을 건너뛰거나 현장의 피해를 줄입니다. |

잠입할 때 선택하는 가면은 **서기·정비공·통역사·도박사** 4종입니다. 기록 열람, 시작 장비, EVE 초안 수, 보상 다시 뽑기처럼 서로 다른 능력을 제공합니다. 서기로 시작하며 나머지 가면은 플레이 기록으로 해금합니다.

## 판이 끝나도 남는 것

폐기되면 그 판의 진행과 모듈은 잃습니다. EVE의 기억, 해금된 가면, 최고 구출 기록은 다음 잠입으로 이어집니다.

게임 안에서 공식 기록과 생존자의 무전 이력을 다시 읽고, 지난 결말을 확인하거나 진행 기록을 JSON으로 내려받을 수 있습니다. 데스크톱과 모바일을 지원하며, 시작 화면의 배경 움직임은 끌 수 있습니다.

## 플레이하기

[thelastvote.ai-ve.uk](https://thelastvote.ai-ve.uk)에 접속해 일반 계정을 만들고 **새 게임**을 시작하세요. 진행 중인 판은 **이어하기**로 돌아올 수 있습니다. 해커톤 전용 시연 모드는 종료했습니다.

AI 연결이 끊기거나 요청 제한에 도달하면 화면에 대체 진행 상태를 알리고 규칙 기반 응답으로 게임을 이어갑니다. 이때는 실제 AI와 대화할 때의 반응과 차이가 있습니다.

## 개발 환경에서 실행

Node.js 24 이상이 필요합니다. 계정과 진행 상태는 SQLite에 저장합니다.

```bash
git clone https://github.com/Arcosium/thelastvote.git
cd thelastvote
npm ci
npm run build
npm start
```

기본 주소는 `http://127.0.0.1:8682`입니다. 실제 AI를 사용하려면 서버 환경에 `CROCHE_PROJECT_KEY`와 `CROCHE_SERVER_KEY`를 설정하세요. 키가 없으면 대체 진행으로 실행합니다. 서버 키는 브라우저 코드나 저장소에 넣지 않습니다.

빌드 전에 게임 이미지·음원·글꼴을 자산 manifest에 따라 내려받고 크기와 SHA-256을 확인합니다. 같은 파일이 이미 있으면 다시 받지 않습니다. 자산 출처는 [자산 안내](docs/MINJO-ASSET-SOURCES.md)에 정리했습니다.

개발 화면은 서버를 켜 둔 상태에서 `npm run dev`로 실행합니다. 검사는 `npm test`와 `npm run check`를 사용합니다.
