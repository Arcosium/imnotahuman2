## 생존자 서사와 인용 동선

제작자 확인에 따라 AI 판단의 변동성을 게임 난이도로 유지했다. 이번 변경은 인물 무전, 결과에 따른 마지막 소식, 기록을 인용해 대응하는 동선에 집중했다. 위원 지시문과 판정 기준을 수정하지 않았다.

Figma Community의 Game UI Dark Fantasy RPG를 다시 검색하고 제작자 UXzavr(Sergey)의 Figma Forum 공개 Dialogue 이미지를 직접 열어 확인했다. Community 원본은 접근 제한으로 열리지 않았고 실제 Design fileKey가 없어 MCP로 원본을 읽지 않았다. 인물 이름·역할·발언의 위계와 대화·행동 영역을 나누는 구성을 참고했다. 외부 인물 이미지나 컴포넌트를 복제하지 않았다. 출처와 원본 접근 제한은 설계서의 링크와 같다. 확인일은 2026-10-14다.

| 위치 | Before | After | Why |
|---|---|---|---|
| 생존자 표시 | 전체 인원과 구역별 숫자 | 윤서·태오·미루의 아침 무전과 수색 이후 회신 | 같은 인물을 기억하며 선택하도록 함 |

| 최근 무전 | 새 영역 없음 | 최근 목소리 하나와 펼침, 새로 끊긴 회선 우선 | 모바일의 첫 화면 길이를 조절 |

| 결말 배경 | 밝은 배경 일부와 회색 서사 글자가 겹침 | 무전 본문 뒤에 어두운 바탕 보강 | 모바일에서 긴 마지막 소식의 대비 확보 |
| 기록·대화 | 읽고 입력란에 직접 다시 작성 | 기존 초안 뒤에 원문 인용, 입력란 포커스 | AI 판단에 반박하는 동선 단축 |

| 종료 기록 | 새로고침 뒤 작전실에서 결말 접근 없음 | 지난 잠입의 결말·무전 다시 열기 | 같은 세션에서 이름과 이야기를 다시 읽음 |

격리된 오프라인 UI 자료로 첫 보고, 연락 두절, 부분 구출, 0명 구출, 인물별 무전 보관소를 1440×900과 390×844에서 렌더했다. 직접 이미지를 확인한 뒤 결말의 본문 배경을 보강하고 다시 촬영했다. 가로 넘침과 브라우저 예외는 없었다. 보고·수색 이후 화면에는 원본 check.py도 실행했고 두 크기에서 결함과 Impeccable 위반이 모두 0건이었다.

기록·위원 발언·변론 인용을 실제 버튼으로 조작해 기존 초안 보존, 자동 제출 없음, 600자 제한 안내와 입력란 포커스를 확인했다. 격리 UI 자료는 실제 사용자 체험이나 승률 검증이 아니다.

근거: `_workspace/story/report-check/`, `loss-check/`, `visual/results.json`, `visual/*-mobile.png`, `visual/*-desktop.png`. 상태별 테스트 11개를 포함한 전체 43개 검사, TypeScript 검사와 프로덕션 빌드를 통과했다.

배포 후 실제 HTTPS 사이트에서도 3일 시연을 진행해 첫 연락, 수색 뒤 무전, 결말, 무전 보관소를 PC·모바일에서 촬영하고 직접 확인했다. 공개 화면의 위원 발언을 인용해 두 번째 발언으로 제출했고, 공식 수색 기록을 변론에 인용했다. 무전 창 Escape 닫기와 새로고침 후 결말 다시 열기도 동작했다. 브라우저 예외·가로 넘침은 0건, AI 대체 진행은 1회였다. 근거는 `_workspace/story/live/`다.
