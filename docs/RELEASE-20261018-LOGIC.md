# 2026-10-18 · 시연 종료와 카드·의심도 수정

해커톤 종료에 따라 일반 계정으로만 게임에 접속한다. minjo의 3일 작전 구조와 카드 화면은 유지했다. AI의 발언·전술 선호·근거 판단은 계속 달라지며, 서버가 책임 귀속과 변화량을 검증한다.

## 시연 모드

- 첫 화면의 시연 메뉴를 기본 비활성화했다. 시연 코드는 재사용할 수 있도록 남겼다.
- `/demo`, `/demo/entry.js`, `/api/demo`, `/api/demo/login`은 기본 HTTP 410이다.
- 기존 시연 쿠키와 시연 계정의 비밀번호 로그인도 일반 게임에 접근할 수 없다.
- 일반 계정과 시연 쿠키가 함께 있으면 일반 계정으로 복귀한다. 일반 계정의 저장 기록은 유지한다.
- 개발·회귀 검사에서만 `ENABLE_HACKATHON_DEMO=1`로 과거 시연 경로를 활성화할 수 있다. 운영 기본값은 비활성이다.

## 의심도와 책임

| 문제 | 변경 후 |
|---|---|
| 인간 편들기 규칙과 AI 평가가 같은 발언에 중복 가산됨 | 동일 발언·관찰자·대상에는 한 번만 적용. 직접 증거가 있으면 해당 규칙의 강도를 사용 |
| 예산 교란 중 직접 인간 발언은 상한 2를 우회 | 직접 증거도 예산 상한을 적용. 잡음까지 있으면 증가량 1 |
| 대역의 공식 발의자는 AI인데 의심은 플레이어에게 적용 | 새 제안의 공식 발의자에게 평가 귀속. 위원의 자기 평가는 제외 |
| 채택되지 않은 전술에 투표해도 마지막 발언자에게 결과 책임 부과 | 채택된 전술에 지지표를 낸 경우에만 최근 공식 제안의 발의 책임 적용 |
| 상한 100에서 실제로 2 올라도 사유에는 9로 기록 | 실제 적용된 변화량으로 기록 |
| hold 평가가 직전의 유효한 증가 근거를 덮음 | 수치 변화가 없으면 마지막 변화의 근거 보존 |
| AI가 배열 대신 객체·null을 반환하면 정상 발언까지 대체 처리 | 평가 항목만 검증·제외. 정상 발언은 유지 |
| 변론이 심의 대상과 관계없는 위원의 의심을 변경 | 해당 변론의 심의 대상에 대한 평가만 허용 |

기록 위조는 이미 들은 발언에 대한 의심을 되돌리는 카드가 아니다. 공식 발의자를 바꿔 이후 작전의 발의 책임을 옮긴다. 플레이어가 채택된 작전에 지지표를 던지면 지지 책임은 남는다. 이 조건을 카드 설명과 사용 결과에 명시했다.

## 카드

- 카드별 사용 가능 여부와 유효 대상을 서버에서 계산해 화면에 전달한다.
- 대역이 이미 대기 중이면 두 번째 대역으로 덮어쓰지 않는다. 카드를 보존한다.
- 이미 적용된 보호 효과, 같은 현장의 비상 통로, 이미 조작된 센서에 중복 사용을 막는다.
- 위조할 자기 제안이 없거나 대역을 쓸 발언 기회가 없으면 사용을 막는다.
- 가짜 센서와 비상 통로는 당일 확정 현장에만 사용할 수 있다.
- 설득할 발언이 더는 남지 않았으면 가짜 센서를 소비하지 않는다.
- 가짜 센서는 공식 보고 신호만 바꾼다. 실제 현장 피해 계산에 쓰는 원래 센서는 서버 내부에 보존한다. 조작 여부가 위원에게 전달되지 않으며, 이후 발언부터 조작된 보고를 근거로 설득할 수 있다.
- 작전 예상 인원과 실제 집행은 같은 서버 계산을 사용한다.
- 카드 결과 창에서 이간의 상호 의심 변화, 위조된 기록 번호, 다음 발언 대역을 확인한다.
- 무전 증폭·시선 추적·표 읽기의 결과는 `모듈 · 작전 정보`에서 다시 확인할 수 있다.

## AI 집행 도구

실제 연결 검사 중 작전·판결 도구 담당이 게임 소거 표현을 현실 요청으로 오인해 실행을 멈추는 경우를 확인했다. 담당 지침과 도구 설명에 허구 게임의 상태 객체만 갱신하며 현실의 사람·장비와 연결되지 않는다는 범위를 명시했다. 도구의 권한 검사와 중복 실행 방지는 유지한다.

## 화면과 요청 처리

| 위치 | 수정 전 | 수정 후 | 이유 |
|---|---|---|---|
| 카드 클릭 후 전투 화면 | 하단 카드로 초점이 이동하면서 전체 배경이 스크롤되고 상단 메뉴가 잘림 | 전투 배경에 `overflow: clip` 적용 | 배경은 고정하고 대화·모달 안에서만 스크롤 |
| 정보 카드 | 결과가 숨겨진 이전 화면에만 표시 | 사용 결과 창과 보고·토론·작전의 정보 메뉴에서 표시 | 사용 효과를 실제 화면에서 확인 |
| 대화 | 새 응답 뒤에도 이전 대화가 먼저 보임 | 대화 영역 내부를 최신 발언으로 이동 | 의심 변화와 근거를 함께 읽기 |
| 중복 클릭 | React 갱신 전에 요청이 두 번 출발할 수 있음 | 동기 요청 잠금과 기존 서버 버전 검증 병행 | 카드·발언 중복 소비 방지 |
| 다음 날 판결 선택 | 이전 날 폐기 찬성 선택이 남을 수 있음 | 날짜 변경 시 반대로 초기화 | 의도하지 않은 찬성 제출 방지 |

## 검증

- 자동 검사 60개, TypeScript 검사, 프로덕션 빌드 통과.
- 기존 인증·저장·회귀 검사와 카드·의심도 12개, 시연 종료·동시 요청 검사를 실행했다.
- 별도 테스트 DB에서 카드 12종을 모바일 브라우저로 조작했다. 전 종류의 사용 결과와 중복 사용 차단을 확인했다. 이 검사는 카드 획득 확률을 기다리는 대신 테스트 계정에 전체 인벤토리를 준비했다.
- 일반 계정의 3일 플레이에서 보고, 사건, 토론, 카드, 작전, 변론, 판결, 보상, 종료를 실제 브라우저로 진행했다.
- 집행 역할 설명을 보완한 뒤 실제 브라우저로 첫날을 다시 진행했다. AI 요청 8회, 사용량 보고 10건, 작전·판결 도구 각 1회 모두 Croche 경로, 대체 진행 0회를 확인했다.
- 실제 Croche 연결에서 인간 편들기 발언과 예산 카드를 조합했다. 세 위원 모두 의심 24 → 26, 중복 가산 없이 실제 AI 답변이 도착했다.
- 1440×900, 390×844 화면을 검사했다. 카드 조작 뒤 배경 스크롤 0, 상단 메뉴 노출, 가로 넘침 없음과 브라우저 예외 없음을 확인했다.
- Arka 기계 검사에서 레이아웃·이미지·요청·콘솔 오류는 없었다. 기존 타이틀의 장식 두 개가 애니메이션 중 투명해지는 `buried-raster` 한 묶음은 의도한 minjo 모션이라 유지했다.

실제 AI의 문장 품질이나 판단 결과가 항상 같다는 의미는 아니다. 외부 응답 지연·도구 실행 누락은 기존 대체 진행으로 이어지며, 작전과 판결의 실제 상태 변경은 서버에서 한 번만 집행한다. 과거에 쌓인 의심을 추정해 소급 변경하지 않았다.
