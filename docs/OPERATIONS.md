# 운영·시연 안내

## 접속

사이트는 https://thelastvote.ai-ve.uk 이다. 일반 사용자는 ‘계정 만들기’에서 영문·숫자·밑줄로 된 아이디와 10자 이상의 비밀번호를 정한다. 일반 계정은 7일판이며 진행은 로그인한 계정에 저장된다.

시연 링크는 https://thelastvote.ai-ve.uk/demo 이다. 비밀번호 입력 없이 시연 계정으로 접속한다. 일반 계정의 쿠키는 유지하고 별도 시연 쿠키를 발급한다. 같은 브라우저로 다시 방문하면 현재 판을 이어가며, 다른 브라우저는 별도 게임을 갖는다.

## 3일 시연 동선

1. `/demo`에 접속해 서기 직업을 확인하고 `잠입 시작`을 누른다. 시드는 `demo-0` 하나이며 서버가 다른 구성 요청도 같은 시드로 처리한다.
2. EVE 비공개 무전에서 빈 구역을 확인한다. 첫날 발전소는 0명이다. `토론 입장`을 누른다.
3. `수색 유도 대상`에서 발전소 선택 → `빈 구역으로 유도` → `초안 1` → `전송`. AI 처리 중에는 중복 클릭하지 않는다.
4. `위원 판단`에서 사유 확인 → `닫기`. 필요하면 `기록 인용`에서 문장을 입력란에 인용한다. 하루 발언은 2회까지다.
5. `토론 종료 · 작전 결정` → 구역 선택 → 해당 구역에 투표. 다수표 구역을 수색하고 동률이면 탐지 신호가 높은 구역을 택한다.
6. 변론을 입력한 뒤 `최종 심의 진행`. 생존하면 모듈을 선택한다. 획득만으로 효과가 적용되지 않으며 다음 작전 단계의 `위장 모듈` 메뉴에서 직접 사용한다.
7. 2일차의 예산 삭감 보고를 확인하고 `토론 입장`을 누른다. 이 시연 사건에는 별도 찬반 선택이 없다. 매일 비공개 무전과 센서 수치를 다시 확인한다. 3일차 심의 뒤 결말과 `이번 회선 사용 기록`을 확인한다.

같은 초기 시드라도 AI 답변·판단과 플레이어 선택으로 결과가 달라진다. 초기 구성 고정은 재현성 조치이며 모든 입력·네트워크 장애가 사라진다는 보장은 아니다. 응답 실패나 예산 제한 때 대체 진행을 표시하고 정형 응답·서버 집계로 이어간다. 발표에서는 대기 시간이 길어지면 보관한 실제 캡처로 설명한다.

## 생존자 이야기와 기록 인용

업데이트 뒤 새로 시작한 판에는 윤서·태오·미루의 무전이 나온다. 이미 진행 중이던 판은 기존 기록을 보존하며 다음 판부터 적용한다. 보고 화면의 세 인물 무전을 읽고, 수색 뒤에는 누가 다시 응답하는지 확인한다. 결말에서 인물별 마지막 소식을 읽는다. 작전실의 ‘지난 잠입 보기’로 다시 열 수 있다. 시연 계정은 같은 로그인 세션 안에서만 이전 판을 이어 본다.

무전은 비밀 채널이며 위치를 공개하지 않는다. EVE를 넘겨도 불씨의 연락은 이어진다. 플레이어가 폐기되거나 철수한 경우에는 남은 인물의 행방을 미확인으로 표시한다.

토론·변론 중 ‘기록 인용’ 또는 ‘전체 대화’에서 ‘입력란에 인용’을 누르면 기존 초안 뒤에 인용문이 붙는다. 자신의 반박을 덧붙이고 직접 제출한다. 600자 한도를 넘으면 입력을 먼저 정리한다. 인용의 성공이 위원의 동의를 보장하지 않는다.

## 공동 시연과 일일 도전

시연 계정은 세션마다 24시간 동안 20판을 생성할 수 있다. 성공한 로그인은 실패 시도 제한에 합산하지 않는다. 자동 시연 입장은 IP당 10분에 600회다. 비밀번호 방식의 같은 IP 로그인 요청은 10분에 120회, 실패는 15회까지 허용한다. 행사에서 한 IP를 공유해도 정상 접속 15회만으로 차단되지 않는다. 전역 AI 지출 한도와 동시 작업 8개 제한은 유지한다.

일일 도전 기록은 시작한 한국 날짜에 귀속한다. 대체 진행이 발생한 판은 순위에서 제외되며 다시 도전할 수 있다. 시연 계정은 순위에 들어가지 않는다.

## 서버 명령

```bash
cd ~/projects/imnotahuman2
npm ci
npm run check
npm test
npm run build
XDG_RUNTIME_DIR=/run/user/1000 systemctl --user status imnotahuman2
```

변경을 배포할 때 신규 서비스의 재시작 권한을 확인한 뒤 실행한다. ArcAI.ve나 전작을 재시작할 필요는 없다.

```bash
XDG_RUNTIME_DIR=/run/user/1000 systemctl --user restart imnotahuman2
curl -fsS http://127.0.0.1:8682/api/health
curl -fsS https://thelastvote.ai-ve.uk/api/health
```

환경 파일 원본은 `~/vault/imnotahuman2/.env`다. 키 값을 로그나 채팅에 출력하지 않는다.

| 변수 | 기본값·용도 |
|---|---|
| `CROCHE_PROJECT_KEY` | Studio 프로젝트의 공개 키 |
| `CROCHE_SERVER_KEY` | 서버 전용 인증, 브라우저에 전달 금지 |
| `CROCHE_MODEL` | `deepseek/deepseek-v4.1-flash` |
| `PORT` | 8682 |
| `DATA_DIR` | 프로젝트 `data` 링크 |
| `RUN_BUDGET_USD` | 0.5, 다음 AI 작업의 중단 기준 |
| `DAILY_AI_BUDGET_USD` | 5, 한국 날짜 기준 서버 전체 중단 기준 |
| `AI_OFFLINE` | 1이면 SDK 호출 없이 정형 응답으로 검사 |

자동 시연 입장은 demo 역할 계정을 없을 때만 생성한다. 수동 비밀번호 로그인용 시연 계정을 처음 만들 때 `node scripts/create-demo.mjs`를 실행한다. 이미 있으면 보존하며 비밀번호를 다시 생성하지 않는다. 자동 검사도 운영 계정 비밀번호를 변경하지 않는다.

## Croche 확인

CLI 로그인은 사용자가 직접 `croche login`을 실행한다. 계정 키를 SDK 환경 파일에 넣지 않는다. 연결 뒤 에이전트는 프로젝트와 사용량 메타데이터만 확인한다.

```bash
croche auth whoami
croche projects list
node --env-file=.env scripts/croche-smoke.mjs
```

실제 smoke는 모델을 호출하므로 비용이 발생한다. 현재 연결과 사용량은 Studio의 Monitoring → Logs·Activity와 Settings → Budget & limits에서 확인한다. UI 비용은 SDK 보고값이며 Studio의 백그라운드 수집과 시차가 생길 수 있다.

## 백업·복사·GitHub

수정 전 현재 파일과 시각을 확인하고 vault의 날짜별 history에 백업한다. 실행 중인 SQLite 파일을 이동하거나 덮어쓰지 않는다. DB 복구·보관에는 SQLite backup API를 사용한다.

```bash
python3 ~/projects/ArcAI.ve/project_copies.py sync --project imnotahuman2
python3 ~/projects/ArcAI.ve/project_copies.py verify --project imnotahuman2
python3 ~/projects/ArcAI.ve/project_copies.py upload --project imnotahuman2
```

GitHub에는 검사된 복사본만 올린다. projects에서 직접 push하거나 검사 보류 파일을 우회하지 않는다. 자산은 manifest의 해시로 내려받으며 비밀·DB·브라우저 인증 상태는 저장소에 포함하지 않는다.

## 장애 확인

| 증상 | 확인 |
|---|---|
| 사이트 502 | 전용 서비스 상태와 loopback health, 해당 호스트의 터널 경로 |
| Croche 대체 진행 | SDK 서버 키, Studio의 프로젝트 접근·예산, 요청 한도 |
| 오래된 선택 409 | 다른 탭 또는 중복 클릭, 최신 게임을 다시 읽기 |
| 입력 제한 429 | 해당 요청 제한의 만료까지 기다리기 |
| 이미지 없음 | `npm run assets`의 해시 검사와 자산 URL |
| 다른 사람과 시연이 섞임 | 같은 브라우저 쿠키를 공유했는지 확인, 각 기기에서 별도 로그인 |

전체 서버 설정을 초기화하거나 기존 서비스 경로를 바꾸지 않는다. 도메인을 철거할 때도 해당 호스트의 ingress와 DNS만 다룬다. 배선 전후 기록은 `vault/imnotahuman2/wiring/`에 보관돼 있다.

## 시작 화면 영상

반복 자산은 public/assets/title-loop-*.webm 및 *.mp4이고 manifest의 해시로 검증한다. 영상 생성 서비스는 빌드나 게임 실행에 필요하지 않다. 재생 오류가 있어도 정지 배경과 게임 진입은 유지된다. 발표에서 움직임이 부담스러우면 첫 화면 오른쪽 아래의 ‘배경 움직임 끄기’를 누른다. 기기의 ‘동작 줄이기’ 설정이 켜졌다면 영상은 기본적으로 재생하지 않는다.
