# 아임 낫 어 휴먼 2 · 소거 위원회 설계서

2026-10-14. 기준 문서는 Croche 해커톤 게임기획서 4판(2026-10-04)이다. 사용자 지시에 따라 7일 전체 게임과 시연 계정 전용 3일판을 함께 구현한다.

## 플레이 목표

인간 오퍼레이터가 AI 위원회에 잠입해 7일을 버티면서 도시의 생존자를 구한다. 7일째 초기 생존자의 40% 이상이 북쪽 방벽을 넘으면 성공이다. 70% 이상, 40% 이상, 40% 미만의 결말을 구분한다. 폐기되면 진행과 모듈을 잃지만 EVE의 기억, 해금, 최고 기록은 남는다.

판마다 달라지는 AI 답변과 판단이 난이도와 재미의 핵심이다. 같은 논리를 제출해도 위원의 반응과 선택이 달라질 수 있다. 위원 성향은 상대를 읽는 단서이며 고정 정답표가 아니다. 플레이어는 재설득, 기록 인용, 위조와 다른 위원 공략으로 대응한다. AI 판단을 정답표로 대체하거나 설득 성공을 보장하지 않는다. 인원·모듈 소비·투표 집계는 서버가 정확히 처리한다.

## 구현 구조

React 화면과 Node 서버를 분리한다. 서버의 순수 게임 엔진이 모든 상태 전이를 결정한다. SQLite에 계정, 세션, 판과 기록을 저장한다. Croche는 위원의 발언·작전 선호·기록 평가와 EVE 초안을 맡는다. 모델이 제안한 의심 변화는 실제 기록 ID와 허용 범위를 검증한 뒤 적용한다. 모델이나 브라우저가 인원·날짜·폐기 여부를 직접 바꾸지 못한다.

일반 계정은 7일, 서버에 지정된 시연 계정은 3일이다. 시연 계정의 로그인 세션마다 독립된 판을 두어 여러 심사위원이 동시에 플레이해도 충돌하지 않는다. 시연은 두 가지 고정 구성을 고를 수 있다. 일반판은 위원, 거점과 사건을 난수 시드로 구성한다.

## 화면

디자인 방향은 검은 관제실과 심의 기록이다. 배경은 숯빛, 본문은 밝은 회색, 강조는 호박색 하나다. 큰 한글 제목과 촘촘한 숫자 표기를 대비시킨다. 각 단계의 다음 행동, 생존자 수, 위원별 의심을 상단과 옆면에 유지한다. 모바일에서는 현재 결정과 EVE 입력을 먼저 보여 주고 지도·위원 기록은 펼쳐 볼 수 있다. 색만으로 상태를 전달하지 않는다. 지도 아래에는 열·음향·편차·비용 비교표를 둔다. 모듈을 쓰면 바뀐 공식 기록을 바로 표시하고, 수색 뒤에는 실제 득표와 책임을 보여 준다.

Figma Community 검색에서 UXzavr(Sergey)의 Game UI Dark Fantasy RPG를 찾았다. Community 페이지는 robots 제한이 있어 원본 파일을 MCP로 읽지 못했다. Figma MCP 연결은 확인했으나 접근 가능한 실제 fileKey가 없었다. 제작자가 Figma Forum에 공개한 Dialogue 화면을 직접 확인했다. 장면을 넓게 쓰고 선택지를 별도 영역에 두는 위계를 참고한다. 판타지 장식과 원본 이미지·컴포넌트는 복제하지 않는다. 외부 원본의 라이선스를 확인하지 않았으므로 참고 화면은 배포하지 않는다.

## 하루와 판결

보고 → 토론 → 작전 → 판결 → 보상. 토론은 하루 최대 2회, EVE 초안은 최대 4회다. 발언 기록을 남기고 위원별 답변과 수색 선호를 받는다. 메아리는 동료들의 현재 라운드 응답을 읽고 마지막으로 판단한다. 발언 뒤에는 평균 의심의 전후 값과 입장을 바꾼 위원 수를 보여 준다. 작전은 플레이어와 AI 위원의 표로 결정한다. 밤에는 대상별 의심 평균이 가장 높은 개체를 지목하고 변론을 거친 뒤 나머지 개체가 폐기 여부를 투표한다. 동률이면 폐기하지 않는다. AI 위원 폐기와 교체는 다음 날 인원수를 유지한다.

의심은 0~100, 발언 근거는 최대 ±4, 작전 결과는 최대 ±14다. 같은 날 같은 주장과 같은 기록을 근거로 한 반복 평가는 한 번만 적용한다. 문장 정규화·문자 n-gram 유사도와 평가 근거 키를 함께 검사한다. 말투나 특정 단어를 보상하지 않는다. 유효한 기록이 없는 AI 평가는 무효다.

## 콘텐츠

7종 위원, 4곳 거점, 6종 중간 사건, 12종 모듈, 4종 가면을 다룬다. 가면과 콘텐츠는 플레이 기록으로 해금한다. 재인증 등급에 따라 위원은 5→6→7명으로 늘어난다. 추적 사건에서는 EVE 희생 또는 거점 희생을 선택한다. 일일 도전은 날짜로 구성을 고정하고 서기 가면만 허용한다. AI 발언의 비결정성 때문에 주간 누적을 비교한다.

새 잠입에서는 수선공 윤서, 수리공 태오, 기록원 미루의 비밀 무전이 이어진다. 세 인물은 원래 거점 인원에 포함된다. 첫날에는 파란 실, 고친 무전기, 이름을 적는 수첩을 소개하고 다음 날에도 같은 사물과 약속을 이어 간다. 수색을 피하면 응답이 이어지며 인물이 있던 거점을 잃으면 회신이 끊긴다. 3일판과 7일판 모두 마지막 날에는 실제 운명에 맞춰 탈출 확인, 방벽 안 잔류, 연락 두절, 행방 미확인을 보여 준다.

무전은 작성된 대사를 게임 상태에 맞춰 선택한다. 위원 AI의 응답이나 판단은 이 서사로 고정하지 않는다. 인물 배치와 탈출자 배정은 기존 구성과 독립된 시드 계산을 사용하므로 신호·사건·보상·구출 인원을 바꾸지 않는다. 위치와 인원 슬롯은 서버에만 남긴다. 인물 무전은 위원회 문맥과 공식 기록에 들어가지 않으며 플레이어에게는 위치를 감춘 채 전달한다.

보고·수색 이후에는 최근 목소리 하나를 먼저 보여 주고 나머지는 펼쳐 읽는다. 새로 끊긴 회선은 앞에 둔다. 결말에는 세 인물의 마지막 소식을 모두 표시한다. 무전 보관소는 인물별로 이전 연락을 묶으며 작전실에서 지난 잠입의 결말을 다시 열 수 있다. 이미 진행 중이던 이전 저장판에는 과거 무전을 소급해서 만들지 않는다.

공식 기록과 위원 대화에는 입력란에 인용하는 버튼을 둔다. 기존 초안을 보존한 채 인용을 추가하고 발언·변론 입력란으로 포커스를 옮긴다. 600자 제한을 넘으면 안내하고 입력을 그대로 보존한다. 제출은 플레이어가 직접 한다. 비밀 무전에는 공개 발언으로 옮기는 버튼을 두지 않는다.

결제·광고는 외부 상점 계약과 실측 단가가 정해지지 않았으므로 금전 거래를 연결하지 않는다. 가면과 모듈을 게임 안에서 체험하도록 구현한다. 유료 상품이 판매 중인 것처럼 표시하지 않는다.

## 운영 경계

Croche 서버 키는 vault의 환경 파일에서 읽는다. SDK와 기억 저장소는 서버에만 둔다. 판별 호출 상한과 전역 일일 지출 차단을 함께 적용한다. 시간 제한이나 잘못된 출력은 규칙 기반 대체 진행을 사용하고 화면의 연결 상태와 비용에 이를 표시한다. 미수신 비용을 0원 실측으로 표시하지 않는다. 실제 응답·도구·사용량을 확인한 뒤 기술설명서에 결과를 적는다.

전용 서비스와 포트를 사용하고 기존 ArcAI.ve나 전작 서비스를 재시작하지 않는다. 사용자 지정 도메인은 기존 shared-apps 터널에 추가한다. GitHub 업로드는 검사된 github 복사본만 사용하며 저장소는 private로 만든다.
