# The Last Vote 이름 정리

게임 표시 이름은 **The Last Vote**, 패키지·저장소·배포 서비스 이름은 `thelastvote`로 통일한다. 운영 주소는 https://thelastvote.ai-ve.uk, 공개 저장소는 https://github.com/Arcosium/thelastvote 다.

README는 세계관, 3일 동안의 구출 목표, 하루의 진행, AI 설득, 모듈 카드와 가면, 반복 플레이 설명을 중심으로 다시 썼다. 초기 기획과 과거 시연 동작은 날짜가 있는 문서의 기록으로 구분한다.

## 변경 범위

- npm 패키지와 잠금 파일, Docker 이미지, 배포 유닛, 연결 검사 식별자를 통일했다.
- 이전 사이트의 API 요청 허용 항목을 제거하고 현재 도메인을 사용한다.
- 페이지 설명을 현재 규칙인 3일 잠입과 AI 위원회에 맞췄다.
- 로그인 쿠키를 `thelastvote_session`으로 바꿨다. 운영 환경의 호환 설정을 읽어 유효한 기존 세션을 새 쿠키로 옮긴다. 현재 세션 우선순위와 시연 종료 상태를 유지한다.
- 작업 정본·GitHub 복사본·vault·서비스의 기준 이름을 통일한다. 과거 작업 경로는 비공개 호환 링크로 연결하고 Git 이력과 날짜별 백업은 보존한다.

계정, 비밀번호, 저장된 게임과 AI 기억의 형식은 바꾸지 않는다. DB는 게임 서비스가 멈춘 동안 같은 파일을 이동하고, 새 서비스가 시작하기 전에 파일 해시를 대조한다.

## 검증

자동 테스트 60개, TypeScript 검사, 운영 빌드를 통과했다. 인증 검사에는 유효한 이전 쿠키의 전환, 잘못된 쿠키 거부, 현재 계정 우선, 로그아웃한 토큰 거부, 종료된 시연 세션 차단과 저장판 보존을 포함한다.

공개 소스·파일명과 배포 빌드의 이름 검사, 실제 서비스 상태, 데스크톱·모바일 화면 확인을 배포 절차에 포함한다. 게임 규칙과 협업자가 만든 화면 디자인은 이번 이름 변경의 수정 대상에 포함하지 않는다.

## 운영 화면 확인

1440×900과 390×844에서 첫 화면을 직접 확인했다. 화면 넘침, 깨진 이미지, 요청·콘솔 오류는 발견되지 않았다. 스타일 검사에서 표시된 두 항목은 기존 장식 애니메이션이 희미해지는 순간의 낮은 투명도였다.

| 위치 | Before | After | Why |
|---|---|---|---|
| 페이지 설명 | 이전 플레이 기간·위원 수 | 현재 3일 게임 소개 | 검색·공유 설명을 현재 규칙과 일치 |
| 시작 화면 장식 | 점멸 중 투명도 경고 2건 | 기존 연출 유지 | 사용자 지정 협업자 디자인이며 정보·버튼을 가리지 않음 |
| 운영 경로 | 이름이 서로 다른 소스·서비스 연결 | `thelastvote` 기준 경로 | 배포 명칭 통일, 비공개 호환 링크로 이전 참조 보존 |
