# minjo 브랜치 운영 반영

2026-10-17, `origin/minjo`의 `d2853f72c082b6562074e86a08d22a219e7eecc4`를 기준으로 반영했다. 운영 주소는 https://thelastvote.ai-ve.uk, 자동 시연 접속은 https://thelastvote.ai-ve.uk/demo 이다.

## 반영 범위

전신 캐릭터, 전장 배경, 타로 모듈 카드와 효과, 작전 카드 3종, 배경 음악, 판결 연출, 보상 카드 선택 화면을 반영했다. 데스크톱 구성은 minjo의 디자인을 따른다. 모바일에서 겹치던 브리핑과 잘리던 작전 설명은 세로로 배치했다.

이번 버전은 일반 계정과 시연 계정 모두 3일이다. 첫 현장은 제3 임시 대피소로 고정되며 초기 위원은 사냥개·메아리·감사관이다. 이전 버전의 장소 투표 대신 확정 현장에서 즉시 진입, 구역별 확인, 출구 봉쇄 후 진입 중 하나를 표결한다. 기존 설계서의 7일·수색 구역 선택 설명은 이전 버전 기록으로 보존한다.

## 운영 연결과 보완

- 현재 도메인의 요청 허용 설정, `/demo` 자동 접속, 일반 계정과 분리된 시연 쿠키를 유지했다. 시연 버튼으로 재접속해도 진행 중인 판을 덮어쓰지 않는다.
- 시연 시드는 `demo-0`, 직업은 서기로 고정했다. Croche의 발언과 판단은 실제 AI가 생성한다.
- 기존 계정·저장 DB와 환경 파일의 vault 연결을 유지한다. 이전 저장판의 기간과 첫 현장은 브랜치의 이행 규칙으로 처리한다.
- 기존 시작 화면의 반복 영상을 유지했다. 브랜치가 참조하지만 포함하지 않은 시작·엔딩 배경 파일에는 기존 운영 이미지를 연결했다.
- 교체된 위원도 화면과 첫 발언에 참여하도록 수정했다. 다음 날의 첫 발언에는 실제 현장 이름을 전달한다.
- 엔딩의 인물 상태와 구출 인원 계산에 같은 탈출 위험을 사용한다. 이미 구출한 사람은 폐기·철수 후에도 구출 상태를 유지하며, EVE 보너스로 사망자가 구출 인원에 다시 포함되지 않게 했다.
- 배포 이미지·음원은 원본 바이트를 유지하고 파일 해시로 식별한다. `assets.manifest.json` 56개 항목으로 크기와 SHA-256을 검증한다.

## 검증

- TypeScript 검사, Vite 운영 빌드 통과.
- 자동 테스트 47개 통과. 인증, 시연 격리, 저장 이행, 작전 투표, 인원 보존, 엔딩, AI 기록 접근과 도구 중복 실행 방지를 확인했다.
- 격리된 오프라인 브라우저에서 3일차 엔딩까지 진행했다. 콘솔 예외와 HTTP 오류는 없었다.
- 1440×900과 390×844 화면을 확인했다. 모바일에서는 브리핑 → 발언 → 작전 표결 → 심의 → 보상 → 2일차 보고까지 실제 조작했다.
- 격리된 데이터 경로에서 실제 Croche로 위원 첫 발언 3개, 토론 응답 3개와 `search.execute` 도구 실행을 확인했다. 모두 `connected`, 대체 응답 0회였다. 해당 점검에 기록된 비용은 $0.002819266이다. 이는 한 차례 연결 점검 비용이며 일반적인 판당 비용 추정치는 아니다.
- `arka-design/scripts/check.py`의 최종 레이아웃·이미지·요청·콘솔 검사에서는 두 해상도 모두 발견 사항이 없었다. 스타일 검사는 깜박이는 장식의 투명도 0을 `buried-raster`로 표시했다. 표시 정보가 아닌 minjo의 의도된 애니메이션이므로 유지했다. 움직임 감소 설정에서는 숨긴다.
