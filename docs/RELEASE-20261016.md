# The Last Vote 본선 버전

운영 주소는 https://thelastvote.ai-ve.uk, 비밀번호 없이 입장하는 3일 시연은 https://thelastvote.ai-ve.uk/demo다. 이전 imnotahuman2.ai-ve.uk의 DNS와 터널 경로를 제거했다. 프로젝트·저장소·서비스 이름은 운영 참조를 보존하기 위해 imnotahuman2를 유지한다.

협업자의 minjo 브랜치 c30d0c2 UI를 현재 게임에 통합했다. 직업 선택·도시 지도·위원 초상·단말 토론 화면을 적용하고 위원 판단·기록 인용·무전·EVE·모듈·전체 대화 기능을 연결했다. 누락된 title-screen-bg.png 대신 기존 관제실 이미지를 사용하고, 이를 바탕으로 Higgsfield에서 반복 영상을 만들었다.

minjo의 AI 훈련 지시문은 기존 도시 4구역 규칙과 달라 적용하지 않았다. 해당 변경을 제외하고 검토한 결과를 작업 정본에 반영했으며, Git 이력에는 검토한 통합 결과를 유지하는 ours 병합으로 minjo의 선행 이력을 연결했다. 바이너리는 기존 저장소 복사 규칙에 따라 manifest와 SHA-256으로 내려받는다.

시연은 서기·demo-0·3일 초기 구성 하나로 고정한다. 방문자별 세션과 진행은 분리하고 같은 브라우저의 재방문에서는 진행을 보존한다. AI 발언·평가·판결은 실제 호출하므로 결과는 달라질 수 있다. 초기 시드 고정은 네트워크 장애나 모든 버그가 사라졌다는 보장이 아니다.

검증은 자동 검사 45개, 타입 검사·빌드, 데스크톱·모바일 12단계 동선, 운영 사이트 실제 3일 1판을 포함한다. 새 첫 화면은 두 크기에서 최종 디자인 검사 결함 0건이었다. 반복 영상은 데스크톱 5회·모바일 크기 3회 경계에서 프레임 간격 33.2~50ms를 기록했고 재생 오류·멈춤이 없었다. 동작 줄이기와 영상 실패 시 정지 배경도 확인했다. 측정의 범위와 남은 한계는 기술설명서·디자인 검증 문서에 있다.

발표 PDF·편집 가능한 PPT·발표 대본·심사 검토는 Croche_해커톤/submissions/the-last-vote-20261016에서 관리한다. 제출 파일은 사용자 지정 이름 00_Arka.pdf이며 발표 순서 확정 후 이름 앞의 00을 바꾼다. 발표 자료와 사용자 문서는 GitHub에 올리지 않고 vault에 별도로 보관한다.
